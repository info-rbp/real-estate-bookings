# Live Domain Smoke Test Checklist

Run after deployment to `https://real-estate.remotebusinesspartner.com.au`:

1. Visit `https://real-estate.remotebusinesspartner.com.au`.
2. Confirm homepage loads.
3. Confirm no browser console errors.
4. Confirm no Appwrite CORS errors.
5. Confirm Appwrite endpoint is correct.
6. Sign up a test user.
7. Sign in with the test user.
8. Send password reset.
9. Update profile settings.
10. Load services list.
11. Submit a test work order.
12. Confirm work order appears in Appwrite.
13. Load admin/staff dashboard.
14. Attempt invoice generation.
15. Export invoice CSV.
16. Confirm errors are controlled and user-friendly.
